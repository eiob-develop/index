# 1-30 빠르게 누르기 (1to30) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 단일 자립 HTML 파일로 "1부터 30까지 순서대로 빠르게 누르는" 시간 도전 게임을 추가하고 허브 페이지(index.html)에 통합한다. UI는 REACTOR(80년대 콘솔) 미학을 따른다.

**Architecture:** 외부 의존성 없는 단일 HTML 파일 1개 신규 + 허브 1개 수정. 인라인 `<style>`/`<script>`로 모든 로직 자립. localStorage로 베스트 기록만 영속화. 정적 사이트 특성상 자동화 테스트 없음 — 각 작업은 브라우저 수동 검증으로 마무리.

**Tech Stack:** Vanilla HTML/CSS/JS. CSS 커스텀 프로퍼티(디자인 토큰), `requestAnimationFrame`(타이머), localStorage(베스트), `prefers-reduced-motion` 미디어 쿼리.

**프로젝트 특수 사항:**
- `.claude/auto-commit.sh` Stop 훅이 매 턴 종료 시 자동으로 `git add -A && git commit && git push`. 따라서 작업 단위 = 의미 있는 한 묶음으로 구성하되, 명시적 commit 단계는 생략한다 (자동화).
- 빌드/패키지 매니저 없음. `1to30.html`을 더블클릭하거나 `start 1to30.html`로 검증.
- 한글 UI + 영문 콘솔 라벨 혼용은 의도된 디자인.

**스펙 참조:** `docs/superpowers/specs/2026-04-27-1to30-game-design.md`

**참조 파일 사전 검토:** 작업 시작 전 `index.html`, `snake.html`, `memory.html` 중 하나를 열어 기존 패턴(상단 ← 홈 링크, 인라인 스타일 구성, localStorage 키 네이밍)을 확인한다.

  const grid = document.getElementById('grid');

  function shuffleNumbers() {
    const nums = Array.from({ length: 30 }, (_, i) => i + 1);
    for (let i = nums.length - 1; i > 0; i--) {
      const j = Math.floor(Math.random() * (i + 1));
      [nums[i], nums[j]] = [nums[j], nums[i]];
    }
    return nums;
  }

  function renderGrid(nums) {
    grid.innerHTML = '';
    nums.forEach((n) => {
      const cell = document.createElement('button');
      cell.className = 'cell';
      cell.dataset.value = n;
      cell.textContent = n;
      grid.appendChild(cell);
    });
  }

  const state = {

  }

## 참고: 자동 커밋 거동

`.claude/auto-commit.sh` Stop 훅이 매 턴 종료 시 다음을 실행:
```
git status --porcelain → 변경 있으면 git add -A → git commit -m "auto: N개 파일 변경" → git push
```

따라서 각 Task 끝에 명시적 commit 단계를 두지 않는다 (자동). 단, 한 턴에 여러 Task를 끝낼 경우 한 커밋에 묶일 수 있음 — 의미 단위가 섞이는 게 거슬린다면 Task 단위로 턴을 끊는다.
