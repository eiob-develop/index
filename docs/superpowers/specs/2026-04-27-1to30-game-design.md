# 1-30 빠르게 누르기 (1to30) — 설계서

**날짜**: 2026-04-27
**유형**: 신규 게임 추가
**상태**: 승인됨, 구현 대기
**비주얼 컨셉**: REACTOR (Tactical CRT Console)

## 1. 개요

기존 5종 미니게임 컬렉션에 6번째 게임으로 "1-30 숫자 빠르게 누르기"를 추가한다. 1부터 30까지의 숫자가 5×6 격자에 무작위 배치되며, 플레이어는 1부터 순서대로 클릭하여 30까지 도달하는 최단 시간에 도전한다. UI는 1980년대 미션 컨트롤 콘솔/타깃팅 시스템을 모티브로 한 **REACTOR** 미학을 따르며, 기존 5게임의 정중한 카드형 다크테마와 의도적으로 차별화한다.

## 2. 게임 규칙

- 페이지 진입 시 1~30 숫자가 5×6 격자에 무작위 배치된다 (게임당 1회 셔플, 게임 중 고정).
- 플레이어가 **1**을 클릭하는 순간 타이머가 시작된다.
- 순서대로 다음 숫자를 클릭하면 해당 셀이 비활성화되고 ✓ 표시된다 (위치 식별을 위해 잔존).
- **잘못된 숫자를 클릭하면 즉시 게임 오버**. 진행 시간은 노출하지 않고 "SEQUENCE BREACH" 모달과 "다시 시작" 버튼만 표시한다.
- 30번 숫자까지 정상 클릭하면 "ALL CLEAR · N.NN초" 모달 표시. 최고 기록 갱신 시 "[NEW RECORD]" 강조.

## 3. REACTOR 비주얼 시스템

| `--bg-cell-cleared` | `#070a0e` | 클릭 완료된 셀 |
| `--accent` | `#f39c12` | 시그니처 오렌지 (인광) |

### 3.2 타이포그래피

- **메인 폰트 스택** (모노):
  ```css
  font-family: 'JetBrains Mono', 'IBM Plex Mono', 'Fira Code',
               Consolas, 'Liberation Mono', Menlo, monospace;
  ```
  외부 폰트 로드 없이 OS 모노폰트 fallback으로 분위기 확보 (자립 HTML 원칙).
- **숫자 폰트**: 동일 모노 스택, `font-variant-numeric: tabular-nums` 강제 (자릿수 변동 방지).
- **셀 숫자 크기**: `clamp(22px, 5vw, 38px)`, `font-weight: 500`
- **상단 바 메타 텍스트**: 11–13px, `letter-spacing: 0.08em`, `text-transform: uppercase`
- **모달 타이틀**: `clamp(28px, 6vw, 48px)`, `font-weight: 600`, `letter-spacing: 0.04em`

### 3.3 격자 디자인

- 5열 × 6행 정사각형 셀
- 셀 크기: `clamp(56px, 13vw, 88px)`
- 셀 간격: 6px
- 격자 컨테이너:
  - 배경 `--bg-surface`
  - 1px 외부 보더 `rgba(243,156,18,0.15)`
  - 코너에 4개의 작은 데코레이션 마커 (8px L자형 오렌지 라인 — 영화 타깃팅 시스템 모티프)
  - 격자 외부 좌측에 행 번호 `01`–`06` 세로 표기 (10px 모노, `--accent-dim`)
  - 격자 외부 상단에 열 라벨 `A`–`E` 가로 표기 (동일 스타일)
  - 격자 우상단에 `// GRID 5×6` 메타 라벨

#### 셀 상태별 스타일

| 상태 | 배경 | 보더 | 텍스트 | 효과 |
|------|------|------|--------|------|
| 미클릭 (대기) | `--bg-surface` | 1px `rgba(243,156,18,0.18)` | `--text-primary` | 없음 |
| 다음 타깃 | `--bg-surface` | 1px `--accent` | `--accent` | `box-shadow: 0 0 0 1px var(--accent), 0 0 18px var(--accent-glow)` + 0.9s 펄스 |
| 클릭 완료 | `--bg-cell-cleared` | 1px `rgba(255,255,255,0.04)` | `--text-muted` | 숫자 자리에 작은 ✓ (10px, `--accent-dim`) |
| 잘못 클릭 (1프레임) | `--danger` | 1px `--danger` | white | 0.15s 후 게임오버 모달로 전환 |

### 3.4 상단 바 (HUD)

좌→우 한 줄 구성, 모노 폰트, 라벨은 `//` 또는 `>` prefix:

```
[← HOME]    // SYSTEM ARMED    // NEXT: 07    T+ 03.42    // BEST: 09.18
```

- **← HOME**: 좌측 끝, 클릭 시 `index.html` 이동, 호버 시 오렌지 강조
- **시스템 상태**: 게임 단계에 따라 동적
  - 시작 전: `// SYSTEM ARMED`
  - 진행 중: 표시 안 함 (NEXT가 그 자리)
  - 종료: `// SHUTDOWN` (실패) 또는 `// MISSION COMPLETE` (성공)
- **NEXT: NN**: 다음 클릭 숫자, 모노 두 자리 (01, 07, 30 등). 0.9s 페이드 펄스 애니메이션.
- **T+ NN.NN**: 경과 시간, 5자리 폭 고정 (예: `T+ 03.42`, `T+ 12.84`). `requestAnimationFrame`으로 매 프레임 업데이트.
- **BEST: NN.NN**: localStorage 베스트, 미존재 시 `BEST: --.--`

### 3.5 게임 오버 모달 (실패)

- 풀스크린 오버레이 `rgba(255,59,48,0.12)` + 격자에 0.4s `shake` 애니메이션 동시 발생
- 중앙 카드:
  - 배경 `--bg-deep`, 1px 보더 `--danger`
  - 상단 작은 라벨 `// FAULT DETECTED` (10px, `--danger`)
  - 큰 텍스트 `[!] SEQUENCE BREACH` (모노, 28-40px)
  - 하단 메타: `EXPECTED: NN  ·  RECEIVED: NN` (실제 기대/누른 숫자)
  - 버튼 `> RESTART` (모노, 호버 시 오렌지 보더)
- 시간 정보 노출하지 않음 (실패는 그냥 실패).

### 3.6 클리어 모달 (성공)

- 풀스크린 오버레이 `rgba(0,217,122,0.08)` + 격자 가장자리부터 안쪽으로 휩쓰는 오렌지 sweep 애니메이션 (0.6s)
- 중앙 카드:
  - 배경 `--bg-deep`, 1px 보더 `--accent`
  - 상단 라벨 `// MISSION COMPLETE` (10px, `--success`)
  - 큰 텍스트 `>> ALL CLEAR` (모노, 28-40px)
  - 시간: 거대 모노 숫자 `12.34` (clamp 48-72px) + 작은 `SEC` 단위
  - 신기록 시 추가 라인: `[NEW RECORD]` (오렌지 깜박임 0.6s 2회)
  - 베스트 비교: `PREV BEST: NN.NN  →  THIS RUN: NN.NN`
  - 버튼 `> RUN AGAIN`

### 3.7 마이크로 인터랙션

| 트리거 | 효과 |
|--------|------|
| 페이지 로드 | 격자가 좌상단부터 우하단으로 8ms 간격 stagger 페이드인 (`opacity: 0 → 1`) |
| 첫 클릭 (타이머 시작) | 화면 전체 1프레임 동안 `--accent-glow` 미세 플래시 (3% 알파) |
| 정상 클릭 | 셀이 0.08s 동안 흰색 플래시 → dim 상태로 전환. NEXT HUD 텍스트가 0.15s에 걸쳐 다음 숫자로 슬라이드 |
| 잘못 클릭 | 셀 1프레임 적색 + 격자 컨테이너 0.4s `shake` (translate ±4px) + 페이지 적색 vignette + 게임오버 모달 |
| 신기록 갱신 | 클리어 모달의 `[NEW RECORD]` 두 번 깜박임 + 격자 가장자리 sweep |
| 다음 타깃 셀 | 0.9s 무한 `box-shadow` 펄스 (글로우 강도 변화) |

### 3.8 배경 효과

- 베이스: `--bg-deep` 단색
- 미세 스캔라인 오버레이:
  ```css
  background-image: repeating-linear-gradient(
    180deg, transparent 0 3px,
    rgba(255,255,255,0.012) 3px 4px
  );
  ```
- 비네트: 외곽 어둡게 (`radial-gradient` 중앙 투명 → 외곽 검정 알파)
- 모션은 없음 (정적 텍스처)

## 5. 데이터 모델

### 게임 상태 (메모리)
```js
state = {
  next: 1,           // 다음에 클릭해야 할 숫자 (1~30, 30 클리어 후 31)
  startTime: null,   // 첫 클릭 시점 ms (Date.now())
  rafId: null,       // requestAnimationFrame ID (시간 표시용)
  ended: false,      // 게임 종료(성공/실패) 플래그
  cells: []          // 셔플된 1~30 배열 (인덱스 = 격자 위치)
}
```

### 영구 저장
- localStorage 키: `1to30-best`
- 값: 초 단위 숫자 문자열 (소수 둘째자리, 예: `"12.34"`)
- 신기록 판정: `currentTime < storedBest || storedBest === null`

## 6. 입력 처리

- **클릭/탭**: 셀을 클릭. 빠른 더블 탭 방지 위해 클릭 시 셀에 `pointer-events: none` 부여 후 8ms 후 클릭 처리.
- **키보드**: 별도 단축키 없음 (모바일 우선, YAGNI).

## 7. 엣지 케이스 및 안정성

- **연속 빠른 탭**: 첫 클릭 처리 중에는 다른 셀 클릭 무시.
- **페이지 언로드 / 새로고침**: 진행 중 게임은 폐기. localStorage엔 best만 유지.
- **localStorage 비활성화 환경**: try/catch로 감싸 best 저장/읽기 실패 시 무시 (메모리 best로 대체).
- **모바일 가로/세로 회전**: CSS만으로 자동 대응. 회전 중 게임 상태는 유지.
- **스크롤 방지**: 게임 중 모바일에서 더블탭 줌 방지 (`touch-action: manipulation`).
- **OS 모노폰트 부재**: 폰트 스택 마지막 `monospace` 키워드로 시스템 fallback.
- **`prefers-reduced-motion`**: 펄스/sweep 애니메이션 비활성, shake도 비활성. 정적 표시만 유지.

## 10. 비목표 (YAGNI)

다음 기능은 **이번 범위에 포함하지 않는다**:

- 난이도 선택 (1-25 / 1-30 / 1-50 등)
- 글로벌 랭킹 / 백엔드 연동
- 사운드 효과 (콘솔 비프음 유혹은 있으나 자립 HTML 원칙 + YAGNI)
- 일일 챌린지 / 시드 기반 동일 격자
- 통계 (시도 횟수, 평균 기록 등)
- 다크/라이트 테마 토글 (REACTOR는 다크 전용)
- i18n (한국어 + 영문 라벨 혼용 의도, 이는 디자인 일부)
- 외부 폰트 로드 (성능 + 자립 원칙)

이 항목들은 향후 별도 후속 작업으로 분리한다.
