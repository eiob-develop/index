# 1-30 빠르게 누르기 (1to30) — 설계서

**날짜**: 2026-04-27
**유형**: 신규 게임 추가
**상태**: 승인됨, 구현 대기

## 1. 개요

기존 5종 미니게임 컬렉션에 6번째 게임으로 "1-30 숫자 빠르게 누르기"를 추가한다. 1부터 30까지의 숫자가 5×6 격자에 무작위 배치되며, 플레이어는 1부터 순서대로 클릭하여 30까지 도달하는 최단 시간에 도전한다.

## 2. 게임 규칙

- 페이지 진입 시 1~30 숫자가 5×6 격자에 무작위 배치된다 (게임당 1회 셔플, 게임 중 고정).
- 플레이어가 **1**을 클릭하는 순간 타이머가 시작된다.
- 순서대로 다음 숫자를 클릭하면 해당 셀이 비활성화되고 ✓ 표시된다.
- **잘못된 숫자를 클릭하면 즉시 게임 오버**. 진행 시간은 노출하지 않고 "❌ 실패" 모달과 "다시 시작" 버튼만 표시한다.
- 30번 숫자까지 정상 클릭하면 "🎉 클리어 / N.NN초" 모달 표시. 최고 기록 갱신 시 "🏆 신기록!" 강조.

## 3. 화면 구성

### 상단 바 (top-bar)
- 좌측: ← 홈 (index.html 링크)
- 중앙: 다음 숫자 힌트 ("다음: **N**", 오렌지 펄스 애니메이션)
- 우측 1: 경과 시간 (실시간 업데이트, 소수 둘째자리)
- 우측 2: 최고 기록 ("최고: N.NN초", localStorage 미존재 시 "최고: --")

### 게임 영역
- 5×6 격자 (가로 5칸, 세로 6칸)
- 셀 크기: `clamp(50px, 12vw, 90px)` 정사각형
- 폰트 크기: `clamp(20px, 5vw, 36px)`
- 셀 간격: 8px

### 모달 (오버레이)
- 게임 오버: 빨간색 강조, "❌ 실패" 텍스트, "다시 시작" 버튼
- 클리어: 오렌지 강조, "🎉 클리어 / N.NN초", 신기록 시 "🏆 신기록!" 추가, "다시 시작" 버튼
- "다시 시작"은 페이지를 리로드하지 않고 상태만 초기화 + 새로 셔플

## 5. 데이터 모델

### 게임 상태 (메모리)
```js
state = {
  next: 1,           // 다음에 클릭해야 할 숫자 (1~30, 30 클리어 시 31)
  startTime: null,   // 첫 클릭 시점 ms (Date.now())
  rafId: null,       // requestAnimationFrame ID (시간 표시용)
  ended: false       // 게임 종료(성공/실패) 플래그
}
```

### 영구 저장
- localStorage 키: `1to30-best`
- 값: 초 단위 숫자 (소수 둘째자리, 예: `12.34`)
- 신기록 판정: `currentTime < storedBest || storedBest === null`

## 6. 입력 처리

- **클릭/탭**: 셀을 클릭. 빠른 더블 탭 방지 위해 클릭 시 셀에 `pointer-events: none` 부여 후 8ms 후 클릭 처리.
- **키보드**: 별도 단축키 없음 (모바일 우선, YAGNI).

## 7. 엣지 케이스 및 안정성

- **연속 빠른 탭**: 첫 클릭 처리 중에는 다른 셀 클릭 무시.
- **페이지 언로드 / 새로고침**: 진행 중 게임은 폐기. localStorage엔 best만 유지.
- **localStorage 비활성화 환경**: try/catch로 감싸 best 저장/읽기 실패 시 무시 (메모리 best로 대체).
- **모바일 가로/세로 회전**: CSS만으로 자동 대응. 회전 중 게임 상태는 유지.
- **스크롤 방지**: 게임 중 모바일에서 더블탭 줌 방지 (`touch-action: manipulation`).

자동화 테스트는 정적 사이트 특성상 적용하지 않는다. 수동 검증 체크리스트:

- [ ] 1번 클릭 시 타이머 시작 확인
- [ ] 순서대로 30까지 클릭 → 클리어 모달 + 시간 표시
- [ ] 잘못된 숫자 클릭 → 즉시 게임 오버 모달
- [ ] 클리어 시 신기록 갱신, 페이지 새로고침 후 "최고: N.NN초" 유지
- [ ] "다시 시작" 누르면 새 셔플로 즉시 재시작
- [ ] 모바일 (좁은 뷰포트) — 셀 크기 자동 축소, 터치 정상 작동

- [ ] index.html 헤더 "6가지 클래식" 표시
- [ ] ← 홈 링크로 index.html 복귀

## 10. 비목표 (YAGNI)

다음 기능은 **이번 범위에 포함하지 않는다**:

- 난이도 선택 (1-25 / 1-30 / 1-50 등)
- 글로벌 랭킹 / 백엔드 연동
- 사운드 효과
- 일일 챌린지 / 시드 기반 동일 격자
- 통계 (시도 횟수, 평균 기록 등)
- 다크/라이트 테마 토글
- i18n (한국어만 지원)

이 항목들은 향후 별도 후속 작업으로 분리한다.
